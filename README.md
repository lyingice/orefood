# 矿物食品 · Ore Food

把矿物做成能吃的食物。**5 种矿物 × 10 种食物 = 50 种矿物食品**，自带五个食物附魔；
吃一口只掉耐久、不掉物品，一块能啃很多次。

## 特性

- **50 种矿物食品**：铜 / 铁 / 金 / 钻石 / 下界合金 × 牛排 / 面包 / 鸡肉 / 鳕鱼 / 羊肉 / 猪排 / 河豚 / 兔肉 / 腐肉 / 鲑鱼。
  营养与饱和度 = 原版对应食物 × 矿物倍率，矿物等级越高越顶饱。
- **耐久即「能吃几次」**：铜 8 次、铁 16 次、金 32 次、钻石 64 次、下界合金 128 次；
  每口扣 1 点耐久，扣完才消失。支持铁砧用对应矿物修复，兼容耐久附魔；创造模式不消耗。
- **五个食物附魔**：强效恢复 / 肾上腺素 / 强身健体 / 饱腹 / 盛宴（宝藏附魔），吃下即触发药水效果；
  物品提示框按原版药水格式预览全部效果与时长。
- **五级合成链**：工作台逐级升级（铜 → 铁 → 金 → 钻石），下界合金走锻造台。
- **负面效果是刻意设计**：河豚 / 腐肉保留原版负面效果，时长随矿物等级放大；
  下界合金还会把部分 I 级效果提到 II 级。
- **模组兼容**：食物属性按真实数值注册——AppleSkin 数值预览、精妙背包自动喂食开箱即用；
  JEI 中每种食品各占一条；Enchantment Descriptions 提供附魔描述；KubeJS 可脚本扩展新口味。

## 安装

下载对应平台的 jar（或按下文自行构建），放入 `.minecraft/mods` 文件夹。
可选联动：AppleSkin、Enchantment Descriptions（需 Balm / Bookshelf 等前置）、KubeJS。

## 从源码构建

三个平台的 Gradle 版本互不兼容，根构建只做转调：

```bash
./gradlew buildAll                 # 三个平台依次构建，产物在各模块 build/libs/
cd <模块> && ./gradlew build       # 单独构建某一平台（runClient / runServer / runData 同理）
```

数值与物品清单只改 common 的 `OreFoodTable`（纯 JDK，三平台共用），改完重跑资源生成器——
详见 [AGENT.md](AGENT.md) 第二节。
