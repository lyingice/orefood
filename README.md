# 矿物牛排 · Ore Food

把矿物做成能吃的食物。**5 种矿物 × 10 种食物 = 50 种矿物食品**；**五个食物附魔**，
吃下去按附魔等级给你药水效果；而且吃完**不掉物品、只掉耐久**，一块能啃很多次。

支持三个平台：**Forge 1.20.1**、**NeoForge 1.21.1**、**NeoForge 26.1.2**。

---

## 加了什么

### 50 种矿物食品

十种食物：**牛排 / 面包 / 鸡肉 / 鳕鱼 / 羊肉 / 猪排 / 河豚 / 兔肉 / 腐肉 / 鲑鱼**
五种矿物：**铜 / 铁 / 金 / 钻石 / 下界合金**

物品 id 就是「矿物_食物」：`orefood:copper_beef`、`orefood:diamond_bread`、
`orefood:netherite_salmon`……

**营养与饱和度 = 原版对应食物 × 矿物倍率**：

| 矿物 | 营养倍率 | 饱和度倍率 | 例：牛排 | 例：面包 |
|---|---|---|---|---|
| 铜 | ×0.75 | ×0.75 | 6 / 9.6 | 4 / 4.5 |
| 铁 | ×1.0 | ×1.0 | 8 / 12.8 | 5 / 6.0 |
| 金 | ×1.0 | ×1.25 | 8 / 16.0 | 5 / 7.5 |
| 钻石 | ×1.25 | ×1.5625 | 10 / 20.0 | 6 / 9.4 |
| 下界合金 | ×1.5 | ×1.875 | 12 / 24.0 | 8 / 11.3 |

**「能吃几次」与附魔能力只由矿物决定**，与食物种类无关：

| 矿物 | 能吃几次 | 附魔能力 | 升级材料 |
|---|---|---|---|
| 铜 | 8 | 1 | 铜锭 |
| 铁 | 16 | 1 | 铁锭 |
| 金 | 32 | 5 | 金锭 |
| 钻石 | 64 | 10 | 钻石 |
| 下界合金 | 128 | 15 | 下界合金锭（锻造台） |

**这里的耐久不是「用坏了就没了」，而是「还能吃几次」**：每吃一口扣 1 点耐久，
扣完这一块才消失——下界合金系列能吃 128 次。因为要带耐久，它们不可堆叠（一格一块）；
创造模式下照旧不消耗。

### 河豚与腐肉：负面效果是刻意的设计

这两种食物在原版就自带负面效果，本模组保留，而且**矿物等级越高持续越久**：

| | 铜 | 铁（= 原版） | 金 | 钻石 | 下界合金 |
|---|---|---|---|---|---|
| 河豚：中毒 / 饥饿 / 反胃 | 30s / 7.5s / 7.5s | 60s / 15s / 15s | 90s / 22.5s / 22.5s | 120s / 30s / 30s | **150s / 37.5s / 37.5s** |
| 腐肉：饥饿（80% 概率） | 15s | 30s | 45s | 60s | **75s** |

升级只**延长持续时间**，**不提升效果等级**——下界合金河豚的中毒依然是 I 级。
其余八种食物没有任何负面效果（纯增益）。

### 五个食物附魔

都只能附在**能吃的物品**上。吃下带附魔的食物时生效：

| 附魔 | 最大等级 | 吃下去得到什么 |
|---|---|---|
| **强效恢复** | 4 | 瞬间治疗 + 生命恢复（附魔几级就是几级药水；生命恢复持续 等级×5 秒） |
| **肾上腺素** | 3 | 力量（等级×5 秒）+ 速度（等级×10 秒） |
| **强身健体** | 5 | 生命吸收（跟随附魔等级）+ 抗性提升 II（40% 减伤），持续 等级×20 秒 |
| **饱腹** | 3 | 在原食物之外额外回 等级×2 点饱食度 |
| **盛宴** | 3 | 饱和效果，每级 1 分钟（**宝藏附魔**，附魔台刷不出） |

### 合成配方

**每种食物各有一条五级链**，与以前牛排那条一模一样：

```text
8 个矿物 + 原版食物            → 铜<食物>        （工作台）
8 个铁锭 + 铜<食物>            → 铁<食物>        （工作台）
8 个金锭 + 铁<食物>            → 金<食物>        （工作台）
8 个钻石 + 金<食物>            → 钻石<食物>      （工作台）
模板 + 下界合金锭 + 钻石<食物>  → 下界合金<食物>   （锻造台）
```

以面包那条链为例：`8 铜锭 + 面包 → 铜面包`、`8 铁锭 + 铜面包 → 铁面包`、……、
最后 `锻造台：模板 + 下界合金锭 + 钻石面包 → 下界合金面包`。

> 中间那一格**必须**是正确的那一级——拿钻石面包去配铜面包是配不出来的。

几条容易搞混的规则：

- **附魔 I 级 = 药水 I 级**（「强效恢复 I」给的是生命恢复 I，不是 II）；
- **抗性提升固定 II 级**（40% 减伤），不随附魔等级变化——同一附魔的生命吸收才跟着等级走；
- **盛宴是宝藏附魔**，只能从战利品箱、交易等途径拿到。

### 提示框会告诉你会得到什么

拿着带附魔的矿物食品，物品提示框里会像原版药水那样逐条列出效果、等级和时长，
不用去猜「强效恢复 III 到底回多少」。显示格式与原版药水完全一致；
矿物河豚 / 矿物腐肉自带的负面效果也会一并列出。

### 装了 JEI 时

50 种矿物食品天然**各占一条**，合成表里的产物与材料也都显示成对应那一级的贴图与名字。

## 怎么用

1. **拿到食物**：创造模式物品栏的「食物与饮品」页里有全部 50 种；生存模式从铜级开始合成。
2. **附魔**：
   - **强效恢复 / 肾上腺素 / 强身健体 / 饱腹**是普通附魔——附魔台能刷出来，
     村民可能卖，战利品箱里也开得到；
   - **盛宴**是**宝藏附魔**：附魔台永远刷不出，但有几率出现在战利品箱里，
     图书管理员也可能出售（获取方式和原版「经验修补」一样）。
3. **吃**：拿在手上右键长按。吃一次扣一点耐久，附魔效果随之触发。
4. **看效果**：鼠标悬停在物品上，提示框里会列出当前附魔与食物本身会带来的效果。
